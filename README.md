A one-line excuse from a robot vacuum for missing a spot, written by a program for make.fun's "The Robot Vacuum's Best Excuse" competition. Deadpan, rooted in the vacuum's own world, and the punch lands at the end: the dust bunny under the bed is no longer dirt to it, it is a tenant paying rent in crumbs — and eviction is above the vacuum's pay grade.

## The line

> The dust bunny under the bed pays rent in crumbs now, so I let it stay. Eviction is above my pay grade.

103 characters, one line, the vacuum itself talking.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt`. It is fully deterministic: the same bytes on every run, no clock, no randomness, no network, no model calls.
